# Odilon Rebelo Advocacia

Site institucional da Odilon Rebelo Advocacia, desenvolvido para apresentar as áreas de atuação, facilitar o contato e publicar conteúdo jurídico.

**Site publicado:** https://odilon-rebelo-advocacia.pauloasr68.chatgpt.site

## Recursos

- Interface responsiva para celulares, tablets e computadores.
- Alternância entre os temas claro e escuro, com preferência persistente.
- Logotipo oficial e identidade visual própria.
- Páginas de áreas de atuação, escritório, contato e artigos jurídicos.
- Blog com categorias, navegação entre conteúdos e páginas individuais.
- Simulador de distrato imobiliário.
- Integração de contato, links de WhatsApp e informações reais do escritório.
- SEO técnico, metadados, sitemap, robots.txt e dados estruturados.
- Navegação acessível por teclado e foco visível.

## Tecnologias

- React, Next.js e TypeScript.
- CSS responsivo com variáveis de tema.
- Vite e Cloudflare Workers.
- Testes automatizados e validação de lint.

## Executar localmente

Requisito: Node.js 22.13.0 ou superior.

```bash
npm ci
npm run dev
```

## Verificações

```bash
npm run test
npm run lint
npm run build
```

O conteúdo, a marca e as informações institucionais pertencem à Odilon Rebelo Advocacia.
